# Задачи для облачных сессий Claude Code

Контекст: Telegram-бот (grammY + Claude Agent SDK), через который владелец общается с Claude Code. Всё в одном
файле `bot.mjs` (~570 строк) + `md2tg.mjs` (Markdown → Telegram HTML). Работает в форум-группе: каждая тема —
отдельная сессия Claude со своей очередью; голос (whisper.cpp), озвучка ответов (piper), фото/файлы, торговые
команды (запускают скрипты соседнего репозитория algolab). Токенов и `.env` в репозитории нет и не нужно —
бота не запускай. Изменения присылай pull request'ом с коротким описанием.

## 1. Тесты и разбиение bot.mjs (без изменения поведения)

- Вынеси чистую логику в модули `lib/` без зависимости от сети: ключ темы по сообщению (`keyOf`, General vs
  тема, личка), контекст ответа (`withReplyContext`: цитата, частичная цитата, служебное сообщение темы),
  очередь темы (`enqueue`/`drain`: по одному ходу на тему, темы параллельно, /stop чистит очередь),
  фильтр доступа (только владелец в своей группе), описания вызовов инструментов (`describeTool`),
  разбиение длинного текста и `md2tg.mjs` (таблицы, вложенные списки, незакрытые блоки кода, экранирование
  `<>&`, длина > 4096).
- Тесты `node --test` без новых зависимостей + `npm test`. Для Telegram и Claude SDK — простые заглушки.
- Отчёт в описании PR: что вынесено, что покрыто тестами, найденные по пути ошибки (файл:строка, сценарий).
